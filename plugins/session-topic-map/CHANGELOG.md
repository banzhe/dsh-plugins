# @banzhe/dsh-session-topic-map

## 0.2.0

### Minor Changes

- 81e00eb: Add `@banzhe/dsh-session-topic-map`: a session-scoped right-sidebar tab that reads the Session's conversation as a graph of progress points, one per reply. The model is only called after the user picks one and confirms; after that the map keeps itself current — a backlog drains in consecutive batches and a quiet conversation is re-checked every two seconds, which never reaches a model — while pausing, switching Session, or leaving the tab stops it and resuming needs a fresh confirmation. A failed run is never retried behind the user's back: the panel names what happened (timeout, unreachable Host, refused request, or an unreadable answer), stops claiming to be running, and offers a retry that is itself a new confirmation. A reply that covers several subjects is one node carrying those topics, and later replies can continue either or both, so convergences and branches are drawn from real progression. Every map is stored per Session, and a stored turn that disagrees with the Session log is re-anchored when the map is read, without another model call. An empty answer advances the checkpoint, while an answer naming only messages outside the range is refused and read again. Clicking a node outlines that reply's turn in the transcript — the transcript exposes no per-message marker, so the panel reports the turn rather than claiming the exact message — and says so when that turn is not rendered. This is the package's first release.
