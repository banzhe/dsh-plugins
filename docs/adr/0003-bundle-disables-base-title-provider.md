# Bundle disables the base title provider

`@deepseek-ai/dsh-base` contributes row `session-title-llm` (`@deepseek-ai/dsh-session-title-first-prompt-llm`), and the title service holds exactly one provider slot — a second `register()` throws — so a rules-based provider cannot coexist with it or wrap it. This Bundle's Patch therefore disables that row and inserts its own, which is broader than the "insert only this Bundle's Loader rows" rule in `.agents/skills/add-dsh-plugin/SKILL.md`: a patch cannot rename a row, only re-configure or disable it. The trade is accepted because it keeps the swap self-contained in one Bundle layer, and rollback is removing the Bundle from the Profile, which re-enables the base row. Every other consumer of that Profile loses the built-in provider while this Bundle is installed.
