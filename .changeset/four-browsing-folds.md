The browsing list is now four independently collapsible groups: unread, pinned, running, and the browsing list itself — "All workspaces", or "All sessions" in the one-list view — which stays last and open by default and keeps its watermarks, group expansion and scroll position while folded. A pinned Session lists only under Pinned and keeps its real status dot there, so a group never stands in for the Session's state. Quick-group rows are the browsing list's own rows — the same status dots, one-at-a-time hover cards, row menu, hover actions, pin mark, rename and relative time — while reordering stays in the tree. The hairline between the block and the tree is gone, and the Windows taskbar pulse no longer treats a pinned Session at rest as a new notification.
